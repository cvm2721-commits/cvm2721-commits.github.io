Privacy Policy

Last updated: September 23, 2026

Who this applies to

Personal Health Tool is used by one person: its owner. It is not available to anyone else.

What data it accesses

With the owner's permission, the tool reads the owner's own data from the Google Health API, using read-only access:

  • Activity and fitness (for example exercise sessions and steps)
  • Health metrics and measurements (for example heart rate)
  • Sleep

It never writes, changes or deletes any data in Google Health.

How the data is used

The data is used only to produce training and recovery summaries for the owner.

Sharing

The data is not sold, not shared with third parties, and not used for advertising.

Storage and deletion

Data and access tokens are kept in storage controlled by the owner. Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops all further reads.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
